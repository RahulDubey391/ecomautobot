Module 2: 25+ Production Tool-Calling Schemas & Function Specs

Reliable agentic architectures require deterministic interfaces. Large Language Models (LLMs) are probabilistic engines; their interaction with internal databases, third-party APIs, and system shells must be constrained by strict schemas, type-safety guarantees, and self-healing validation pipelines.

This module provides production-ready Pydantic v2 models, an automated OpenAPI-to-LLM schema converter, an AST-verified sandboxed execution engine, and zero-shot routing prompts designed to eliminate tool-calling drift, hallucinations, and runtime parameter failures.

1. Pydantic v2 Core Tool Engine & Architecture

Production tool calls must enforce rigid input contracts. Pydantic v2 provides Rust-backed validation speeds and native serialization to JSON Schema Draft 2020-12, fully compatible with OpenAI, Anthropic, and open-source function-calling formats.

1.1 Base Tool Contract

Every tool in your pipeline should inherit from BaseToolModel. This base class enforces: 1. Strict parameter validation (extra="forbid" prevents arbitrary hallucinations). 2. Whitespace stripping on all string inputs. 3. Automated conversion into both OpenAI Function definitions and Anthropic Tool specs.

"""
Core Tool Architecture: Base schema definitions and conversion protocols.
"""

from typing import Any, Dict, Type
from pydantic import BaseModel, ConfigDict


class BaseToolModel(BaseModel):
    """Base class for all production tool parameter schemas."""

    model_config = ConfigDict(
        extra="forbid",
        str_strip_whitespace=True,
        validate_default=True,
        validate_assignment=True,
        populate_by_name=True
    )

    @classmethod
    def to_openai_tool(cls, name: str, description: str) -> Dict[str, Any]:
        """Convert the Pydantic schema to an OpenAI-compatible tool spec."""
        schema = cls.model_json_schema()
        # Clean up metadata titles generated by Pydantic that bloat prompts
        schema.pop("title", None)
        for prop in schema.get("properties", {}).values():
            prop.pop("title", None)

        return {
            "type": "function",
            "function": {
                "name": name,
                "description": description.strip(),
                "parameters": schema,
                "strict": True
            }
        }

    @classmethod
    def to_anthropic_tool(cls, name: str, description: str) -> Dict[str, Any]:
        """Convert the Pydantic schema to an Anthropic-compatible tool spec."""
        schema = cls.model_json_schema()
        schema.pop("title", None)
        for prop in schema.get("properties", {}).values():
            prop.pop("title", None)

        return {
            "name": name,
            "description": description.strip(),
            "input_schema": schema
        }

class ExecuteSQLQuery(BaseToolModel):
    """Execute an analytical, read-only SQL query against the read-replica database."""

    query: str = Field(
        ...,
        description="The raw SQL query string. Must strictly be a single SELECT statement."
    )
    timeout_seconds: int = Field(
        default=30,
        ge=1,
        le=120,
        description="Execution timeout in seconds. Clamped between 1 and 120."
    )
    max_rows: int = Field(
        default=500,
        ge=1,
        le=2000,
        description="The maximum number of rows to return to prevent context window overflow."
    )

    @field_validator("query")
    @classmethod
    def enforce_read_only(cls, v: str) -> str:
        cleaned = v.strip().rstrip(";")

        # Check for multiple statements
        if ";" in cleaned:
            raise ValueError("Multiple SQL statements separated by ';' are forbidden.")

        # Blacklist non-SELECT verbs
        forbidden_patterns = [
            r"\bINSERT\b", r"\bUPDATE\b", r"\bDELETE\b", r"\bDROP\b",
            r"\bALTER\b", r"\bTRUNCATE\b", r"\bCREATE\b", r"\bGRANT\b",
            r"\bREVOKE\b", r"\bEXEC\b", r"\bCALL\b", r"\bMERGE\b"
        ]
        for pattern in forbidden_patterns:
            if re.search(pattern, cleaned, re.IGNORECASE):
                raise ValueError(f"Prohibited SQL operation detected: {pattern.strip('\\b')}")

        # Ensure it starts with SELECT or WITH
        if not re.match(r"^(SELECT|WITH)\b", cleaned, re.IGNORECASE):
            raise ValueError("Query must strictly begin with 'SELECT' or 'WITH'.")

        return cleaned

3. OpenAPI 3.1 to LLM Tool Engine

Production environments frequently already have OpenAPI/Swagger documentation. Instead of hand-authoring Pydantic classes for every service, use this converter to ingest raw OpenAPI 3.1 paths and transform them into OpenAI tool calling declarations.

"""
OpenAPI 3.1 to OpenAI Tool Calling Format Converter.
Direct translation engine preserving schemas, enums, arrays, and descriptions.
"""

from typing import Any, Dict, List


class OpenAPIToolConverter:
    """Transforms arbitrary OpenAPI 3.0/3.1 specs into executable LLM tool specifications."""

    @staticmethod
    def _resolve_schema_property(schema_dict: Dict[str, Any]) -> Dict[str, Any]:
        """Translates OpenAPI parameter schema attributes to standard JSON Schema."""
        prop_type = schema_dict.get("type", "string")
        resolved: Dict[str, Any] = {"type": prop_type}

        if "description" in schema_dict:
            resolved["description"] = schema_dict["description"]

        if "enum" in schema_dict:
            resolved["enum"] = schema_dict["enum"]

        if prop_type == "array":
            items = schema_dict.get("items", {"type": "string"})
            resolved["items"] = OpenAPIToolConverter._resolve_schema_property(items)

        if prop_type == "object":
            resolved["properties"] = {}
            for sub_key, sub_val in schema_dict.get("properties", {}).items():
                resolved["properties"][sub_key] = OpenAPIToolConverter._resolve_schema_property(sub_val)
            if "required" in schema_dict:
                resolved["required"] = schema_dict["required"]

        return resolved

    @classmethod
    def convert(cls, openapi_spec: Dict[str, Any]) -> List[Dict[str, Any]]:
        """Parses an OpenAPI spec dict and emits a list of OpenAI function specs."""
        tools: List[Dict[str, Any]] = []
        paths = openapi_spec.get("paths", {})

        for path, path_item in paths.items():
            for method, operation in path_item.items():
                if method.lower() not in {"get", "post", "put", "patch", "delete"}:
                    continue

                operation_id = operation.get("operationId")
                if not operation_id:
                    # Synthesize deterministic operation name: e.g., post_users_auth
                    clean_path = path.strip("/").replace("/", "_").replace("{", "").replace("}", "")
                    operation_id = f"{method.lower()}_{clean_path}"

                description = operation.get("summary") or operation.get("description") or f"Call {method.upper()} on {path}"

                # Parameters construction
                properties: Dict[str, Any] = {}
                required: List[str] = []

                # Handle Path / Query / Header parameters
                for param in operation.get("parameters", []):
                    param_name = param.get("name")
                    param_schema = param.get("schema", {"type": "string"})
                    prop = cls._resolve_schema_property(param_schema)
                    if "description" in param:
                        prop["description"] = param["description"]

                    properties[param_name] = prop
                    if param.get("required", False):
                        required.append(param_name)

                # Handle JSON Request Body
                request_body = operation.get("requestBody", {})
                content = request_body.get("content", {})
                json_media = content.get("application/json", {})
                body_schema = json_media.get("schema", {})

                if body_schema:
                    body_properties = body_schema.get("properties", {})
                    for prop_name, prop_spec in body_properties.items():
                        properties[prop_name] = cls._resolve_schema_property(prop_spec)

                    for req_field in body_schema.get("required", []):
                        if req_field not in required:
                            required.append(req_field)

                tool_definition = {
                    "type": "function",
                    "function": {
                        "name": operation_id,
                        "description": description.strip(),
                        "parameters": {
                            "type": "object",
                            "properties": properties,
                            "required": required,
                            "additionalProperties": False
                        },
                        "strict": True
                    }
                }
                tools.append(tool_definition)

        return tools

4. Sandboxed Code Execution Pipeline

Letting an LLM execute arbitrary code requires strict isolation. Never execute untrusted LLM-generated code via native eval() or exec().

The pipeline below enforces a multi-layer defense: 1. Static AST Analysis: Rejects code containing dangerous imports, file access, and execution constructs before anything runs. 2. Subprocess Isolation: Runs code in a non-root child process with resource limits (CPU, memory, wall-clock time) and network restrictions.

"""
Multi-Layer Python Execution Sandbox with Static AST Analysis and OS Resource Capping.
"""

import ast
import resource
import subprocess
import sys
import tempfile
from typing import Dict, Any, List


class SecurityViolationError(Exception):
    """Raised when submitted code violates security static analysis checks."""
    pass


class ASTSecurityAuditor(ast.NodeVisitor):
    """Static analysis visitor blocking forbidden operations before interpreter execution."""

    BLOCKED_MODULES = {
        "os", "sys", "subprocess", "shutil", "socket", "requests", 
        "urllib", "http", "posix", "pty", "commands", "builtins"
    }

    BLOCKED_FUNCTIONS = {
        "eval", "exec", "compile", "__import__", "open", "input"
    }

    BLOCKED_ATTRS = {
        "__subclasses__", "__bases__", "__globals__", "__code__"
    }

    def visit_Import(self, node: ast.Import) -> None:
        for alias in node.names:
            base_module = alias.name.split(".")[0]
            if base_module in self.BLOCKED_MODULES:
                raise SecurityViolationError(f"Import of forbidden module: '{alias.name}'")
        self.generic_visit(node)

    def visit_ImportFrom(self, node: ast.ImportFrom) -> None:
        if node.module:
            base_module = node.module.split(".")[0]
            if base_module in self.BLOCKED_MODULES:
                raise SecurityViolationError(f"Import from forbidden module: '{node.module}'")
        self.generic_visit(node)

    def visit_Call(self, node: ast.Call) -> None:
        if isinstance(node.func, ast.Name):
            if node.func.id in self.BLOCKED_FUNCTIONS:
                raise SecurityViolationError(f"Call to prohibited built-in function: '{node.func.id}'")
        self.generic_visit(node)

    def visit_Attribute(self, node: ast.Attribute) -> None:
        if node.attr in self.BLOCKED_ATTRS:
            raise SecurityViolationError(f"Access to dangerous dynamic attribute: '{node.attr}'")
        self.generic_visit(node)


def apply_rlimits(max_memory_mb: int = 128) -> None:
    """Sets Linux OS resource boundaries on the child runner process."""
    # Memory limit
    memory_limit = max_memory_mb * 1024 * 1024
    resource.setrlimit(resource.RLIMIT_AS, (memory_limit, memory_limit))

    # Restrict core dump files
    resource.setrlimit(resource.RLIMIT_CORE, (0, 0))

    # Cap CPU processing time (in seconds)
    resource.setrlimit(resource.RLIMIT_CPU, (5, 5))


class SandboxedCodeExecutor:
    """Executes validated, sandboxed Python code within an ephemeral, resource-constrained subshell."""

    def __init__(self, max_memory_mb: int = 128, timeout_seconds: int = 5):
        self.max_memory_mb = max_memory_mb
        self.timeout_seconds = timeout_seconds

    def execute(self, code: str) -> Dict[str, Any]:
        """Validate, stage, and execute the generated code."""
        # Layer 1: AST Verification
        try:
            tree = ast.parse(code)
            auditor = ASTSecurityAuditor()
            auditor.visit(tree)
        except SyntaxError as e:
            return {"status": "error", "phase": "syntax", "message": f"Syntax Error: {str(e)}"}
        except SecurityViolationError as e:
            return {"status": "rejected", "phase": "security", "message": str(e)}

        # Layer 2: Isolated Process Execution
        with tempfile.NamedTemporaryFile(mode="w", suffix=".py", delete=True) as temp_script:
            temp_script.write(code)
            temp_script.flush()

            try:
                proc = subprocess.run(
                    [sys.executable, temp_script.name],
                    preexec_fn=lambda: apply_rlimits(self.max_memory_mb),
                    capture_output=True,
                    text=True,
                    timeout=self.timeout_seconds,
                    check=False
                )

                return {
                    "status": "success" if proc.returncode == 0 else "failed",
                    "return_code": proc.returncode,
                    "stdout": proc.stdout.strip(),
                    "stderr": proc.stderr.strip()
                }

            except subprocess.TimeoutExpired:
                return {
                    "status": "timeout",
                    "message": f"Process exceeded maximum runtime limit of {self.timeout_seconds} seconds."
                }
            except Exception as e:
                return {
                    "status": "system_error",
                    "message": f"Subprocess initialization error: {str(e)}"
                }

5.2 Deterministic Tool-Caller System Prompt

Place this system prompt into your model's context. It explicitly eliminates markdown wrapping inside tool calls and forbids invented arguments.

You are a Deterministic Tool-Calling Gateway. Your sole responsibility is to evaluate the user query, determine the exact tool required, and emit syntactically and logically valid function-calling parameters.

Operational Constraints:
1. STRICT TYPE ADHERENCE: You must map all inputs strictly to the JSON schemas provided. Missing required arguments will trigger immediate execution aborts.
2. NO HALLUCINATED ARGUMENTS: Never supply extra fields not declared in the tool schema. Set optional fields to their designated default values if unknown.
3. MUTATION GUARDRAIL: When handling financial actions or system operations, verify that an explicit idempotency key or identifier exists in the context. Never invent IDs.
4. ERROR REPAIR PROTOCOL: If returned a schema validation error message, parse the specific failure path, remediate the broken parameter, and re-invoke the tool. Do not apologize or return conversational text during an error loop; emit only the corrected function call.
5. ISOLATION: Never include markdown formatting (like ```json ... ```) in direct parameter values unless the field description explicitly requests markdown syntax.

5.3 Deterministic Tool Execution & Validation Loop

The state machine below intercepts LLM tool calls, validates them via Pydantic v2, routes execution, captures runtime exceptions, and feeds structured error contexts back to the LLM for automatic self-healing.

"""
Self-Healing Tool Validation and Execution Engine.
"""

import json
from typing import Callable, Dict, Any
from pydantic import ValidationError


class ToolExecutionGateway:
    """Manages tool registration, dynamic validation, and self-healing repair attempts."""

    def __init__(self):
        self._registry: Dict[str, Dict[str, Any]] = {}

    def register_tool(
        self,
        name: str,
        schema: Type[BaseToolModel],
        handler: Callable[..., Any],
        description: str
    ) -> None:
        """Register a tool, its validation model, and its execution callable."""
        self._registry[name] = {
            "schema": schema,
            "handler": handler,
            "description": description,
            "spec": schema.to_openai_tool(name=name, description=description)
        }

    def get_registered_specs(self) -> List[Dict[str, Any]]:
        """Retrieve all active tool declarations for model prompt injection."""
        return [meta["spec"] for meta in self._registry.values()]

    def invoke(self, tool_name: str, raw_arguments_json: str) -> Dict[str, Any]:
        """Validate input payloads against the registered model and execute."""
        if tool_name not in self._registry:
            return {
                "success": False,
                "error_type": "ToolNotFound",
                "message": f"Tool '{tool_name}' is not registered with this gateway.",
                "retryable": False
            }

        tool_meta = self._registry[tool_name]
        schema_class: Type[BaseToolModel] = tool_meta["schema"]
        handler: Callable = tool_meta["handler"]

        # Step 1: JSON Parsing
        try:
            parsed_args = json.loads(raw_arguments_json)
        except json.JSONDecodeError as err:
            return {
                "success": False,
                "error_type": "JSONDecodeError",
                "message": f"Failed to parse arguments JSON: {str(err)}",
                "retryable": True,
                "fix_instructions": "Ensure output is well-formed, valid JSON. Strip markdown backticks."
            }

        # Step 2: Pydantic Validation
        try:
            validated_instance = schema_class.model_validate(parsed_args)
        except ValidationError as err:
            # Format concise error breakdown for self-healing
            error_details = []
            for issue in err.errors():
                loc = " -> ".join([str(p) for p in issue["loc"]])
                error_details.append(f"Field '{loc}': {issue['msg']} (Input: {issue.get('input')})")

            return {
                "success": False,
                "error_type": "ValidationError",
                "message": "Parameters failed schema validation rules.",
                "validation_errors": error_details,
                "retryable": True,
                "fix_instructions": "Correct the parameter values according to the validation_errors."
            }

        # Step 3: Deterministic Tool Execution
        try:
            execution_result = handler(**validated_instance.model_dump())
            return {
                "success": True,
                "result": execution_result
            }
        except Exception as handler_err:
            return {
                "success": False,
                "error_type": "ExecutionRuntimeError",
                "message": f"Tool implementation error: {str(handler_err)}",
                "retryable": False
            }

6. Production Readiness Checklist & Failure Modes

6.1 Tool-Calling Failure Matrix

Failure Mode Root Cause Impact Automated Remediation Pattern
Parameter Drift Model invents plausible keys (e.g. user_id instead of customer_id). Schema failure; aborted request. Enforce extra="forbid" in Pydantic. Use structured error-injection to trigger targeted corrections.
SQL Injection via Agent Model writes concatenated inputs containing UNION, DROP, or ALTER. Data loss or exfiltration. Enforce regex validation forbidding non-SELECT tokens. Force parameters through a read-only DB connection user.
Silent Type Coercion Number strings (e.g., "1250") cast to unexpected floats or types. Truncation errors; precision loss in financials. Use strict field validation. Use explicit integer cents (amount_in_cents: int) over float representations.
Context Window Blowout SQL or log inspection returns tens of thousands of rows. Out-of-memory errors; high latency; agent stall. Hard-clamp parameters: max_rows: int = Field(default=500, le=2000). Enforce offset pagination in handlers.
Sandbox Jailbreak Code invokes __subclasses__() or dynamic imports to bypass barriers. Subshell takeover, host compromise. AST Visitor blocks __ access, combined with Linux RLIMIT_AS memory and CPU limits.
